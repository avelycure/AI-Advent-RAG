# День 25 — проверка длинного RAG-чата с памятью задачи

Дата прогона: 5 октября 2026 года (Europe/Moscow). Модель ответа, query rewrite и обновления памяти: `deepseek-flash`; embeddings и поиск: локальная `qwen3-embedding:0.6b`.

## Методика

Проверены два независимых диалога по 10 пользовательских сообщений. На каждом ходе выполнялся тот же production-like конвейер, что и в плагине:

1. обновление структурированной памяти задачи;
2. переформулирование вопроса с учётом недавней истории и памяти;
3. локальный поиск, порог similarity и реранкинг;
4. grounded-ответ DeepSeek;
5. локальная проверка `source`, `section`, `chunk_id` и дословной цитаты.

Ход считался успешным, если ответ содержал хотя бы один проверенный источник, все цитаты дословно присутствовали в индексированных чанках, ссылки `[S…]` соответствовали списку доказательств и среди использованных источников был ожидаемый файл. В финале сценария отдельно проверялись сохранность цели, явно заданных ограничений и пользовательского термина.

## Наблюдение по поиску

Во время первого прогона обнаружился реальный дефект русского поиска: запрос со словом «карбонаре» не совпадал с названием заметки «Паста карбонара», потому что metadata-фильтр сравнивал только полные токены. Из-за этого поиск выбирал семантически похожий, но неверный рецепт. Фильтр дополнен ограниченным сравнением общих префиксов для длинных слов; регрессионный тест подтверждает корректный выбор склонённого русского названия без отключения similarity-порога.

Полные вопросы, ответы, снимок памяти после каждого хода, retrieval-диагностика и проверенные цитаты находятся в `eval/day25-results.json`. Сценарии — в `eval/day25-long-scenarios.json`.
