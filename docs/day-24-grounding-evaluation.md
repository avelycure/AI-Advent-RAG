# День 24 — цитаты, источники и анти-галлюцинации

## Контракт ответа

DeepSeek получает только отфильтрованные чанки и возвращает JSON со статусом, ответом и
массивом доказательств. Для каждого доказательства обязательны `source`, `section`,
`chunk_id` и дословная непрерывная цитата. Перед показом ответа плагин локально проверяет:

1. JSON-схему и непустой ответ;
2. существование каждого `[S…]` среди реально отправленных чанков;
3. точное совпадение `source`, `section` и `chunk_id` с локальным индексом;
4. наличие цитаты внутри текста соответствующего чанка;
5. соответствие ссылок в ответе списку доказательств.

При ошибке выполняется одна попытка исправить структурированный ответ. Если она тоже не
проходит проверку, неподтверждённый текст скрывается и пользователь получает «Не знаю» с
просьбой уточнить вопрос. Если после similarity-порога нет ни одного чанка, генерация ответа
вообще не вызывается.

## Условия проверки

- LLM: `deepseek-flash`, thinking отключён.
- Embeddings: локальная `qwen3-embedding:0.6b`.
- Retrieval: query rewrite, 20 кандидатов, порог `0.35`, максимум 5 чанков.
- Индекс: SHA-256 `3382f4435ec11340c0f1a7eedb6d79f96f73a30bf2111fb9f905eb81a5f4c269`.
- Десять вопросов имеют ответы в тестовом корпусе; слабый запрос W01 проверяется отдельно.
- Смысл ответа относительно цитат проверялся отдельным вызовом `deepseek-flash`, которому
  передавались только вопрос, ответ и выбранные цитаты без внешнего контекста.
